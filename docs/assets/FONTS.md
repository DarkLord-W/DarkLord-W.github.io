# 字体许可

本站有两处使用了自托管的字体子集，均来自 Google Fonts，许可证为 SIL Open Font License 1.1。

## Ma Shan Zheng（马善政毛笔楷书）

- 文件：`poem-brush.woff2`
- 用途：关于页诗句
- 子集：仅包含「朝游东海暮休寒山御六气变乘天地间守静」18 个字
- 来源：<https://fonts.google.com/specimen/Ma+Shan+Zheng>
- 许可：SIL Open Font License 1.1，<https://scripts.sil.org/OFL>

## Noto Serif SC（思源宋体）

- 文件：`poem-serif.woff2`
- 用途：站内中文衬线回退
- 子集：仅包含诗句用字
- 来源：<https://fonts.google.com/noto/specimen/Noto+Serif+SC>
- 许可：SIL Open Font License 1.1，<https://scripts.sil.org/OFL>

## 说明

OFL 允许把字体内嵌或随作品分发，条件是随附本许可声明、且不得单独售卖字体本身。
上面两个文件都经过子集化（只保留用到的字形），原始字体请从上面的来源获取。

其余字形使用系统字体（PingFang SC、微软雅黑、思源黑体等），不随本站分发。
